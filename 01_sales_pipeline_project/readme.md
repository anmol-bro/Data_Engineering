#  Sales Data ETL Pipeline (Python + SQL)
 Project Overview
This project is a simple end-to-end ETL (Extract, Transform, Load) pipeline built using Python and SQLite.  

It reads raw sales data from a CSV file, performs data cleaning and transformation using Pandas, and loads the processed data into a SQLite database for analysis using SQL queries.

---

## Tech Stack
- Python
- Pandas
- SQLite (via sqlite3)
- SQL
